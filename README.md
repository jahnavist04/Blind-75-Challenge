# Blind 75 Challenge 🚀

Welcome to my **Blind 75 Challenge** - a focused journey through 75 essential coding problems commonly used to strengthen **Data Structures & Algorithms** and prepare for technical interviews.

I will be solving every problem in **both Java and Python**, focusing not just on getting the correct answer, but also on understanding the approach, recognizing patterns, and improving problem-solving skills.

---

## 🎯 Why Blind 75?

The Blind 75 is a curated collection of coding problems covering the most important DSA concepts.

Instead of solving random problems, this challenge focuses on building a strong foundation across commonly tested topics and learning how to identify the right approach for a problem.

---

### ☕ Java

### 🐍 Python

## 🔍 What I'm Focusing On

For each problem, the goal is to understand:

- **Problem-solving approach**
- **Optimal solution**
- **Time complexity**
- **Space complexity**
- **Underlying DSA pattern**
- **Why the solution works**
- **How the approach can be applied to similar problems**

---

## 📚 Learning Approach

I will focus on recognizing patterns rather than memorizing solutions.

For every problem, I'll first understand the problem, explore the approach, implement the solution, and then analyze its efficiency.

The same problem will be implemented in both **Java and Python** to develop familiarity with both languages.

---

## 🏆 Goal

The ultimate goal of this challenge is to become more confident with DSA, improve logical thinking, and build a strong foundation for **technical interviews and competitive programming**.

> **75 problems. 2 languages. 1 goal - become better at problem solving. 🚀**
